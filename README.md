# 🎓 IIT Mandi Summer Internship Project

Generative Adversarial Networks (GANs) for Video Dataset Generation

## 📌 Overview

During my internship at IIT Mandi (CAIR), I explored Generative Adversarial Networks (GANs) for synthetic data generation to enhance drone surveillance capabilities.

I implemented and trained:

Vanilla GAN – baseline architecture for image generation

DCGAN – convolution-based GAN for improved image quality

Video GAN – extended GAN framework for generating realistic video sequences

## 📊 Dataset

Robotics Lab Dataset, CAIR, IIT Mandi (drone surveillance domain).

## 🚀 Results

Successfully trained GAN models on domain-specific data.

Observed progressive improvements in image sharpness, realism, and temporal consistency from Vanilla → DCGAN → Video GAN.

## 🛠 Tech Stack

Python, PyTorch

Deep Learning (CNNs, Autoencoders, GANs)
